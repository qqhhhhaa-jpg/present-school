# الشعار وأيقونة التطبيق (المعتمد)

- **الشعار:** كلمة «حاضر» بخط كوفي مدوّر مرسوم خصيصاً، بلونين:
  - الحاء بالأخضر المائي (#0B7F70)، ومعناها «حاضر ✓».
  - باقي الكلمة بالكحلي (#1E2B5C).
  - نقطة الضاد معيّن ذهبي كهرماني (#F2A93B)، ومعناها «عندك جديد».
- `wordmark-on-light.svg`: على الفاتح.
- `wordmark-on-dark.svg`: على الكحلي (أبيض، والحاء أخضر فاتح #34C3AE).
- `wordmark-mono.svg`: لون واحد للطباعة والختم.
- **أيقونة التطبيق:** كحلي عميق بإضاءة خفيفة، وإطار ذهبي رفيع، والشعار بالنص.
  - `app-icon-ios.svg`: 1024×1024 بدون زوايا (النظام يدوّرها).
  - `app-icon-rounded.svg`: للعروض والمتاجر.
  - `android-adaptive-foreground.svg` + `android-adaptive-background.svg`: أيقونة أندرويد التكيفية.
  - `android-monochrome.svg`: أيقونة أندرويد 13 أحادية اللون.
  - `favicon.svg`: أيقونة المتصفح.
- لا تشوّه الشعار ولا تغيّر ألوانه ولا تضعه على صورة.
