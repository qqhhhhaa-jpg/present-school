# Button

زر واحد رئيسي `hd-btn-primary` (أخضر) في كل شاشة للفعل الذي جاء المستخدم من أجله.

- `hd-btn-primary`: الحفظ والبدء والإرسال. `hd-btn-brand`: فعل مهم ثانٍ بجانب الرئيسي (افتح السبورة). `hd-btn`: الأفعال العادية. `hd-btn-danger`: الحذف والإلغاء النهائي فقط.
- المستهلك يوفّر: عنصر `<button>` والنص، وأيقونة اختيارية قبل النص.
- النص فعل واضح: «تحميل PDF» لا «تحميل». ارتفاع 46px ولا يقل عن 44px.
- لا تضع زرّين رئيسيين في نفس المكان.
