# FaceQualityMeter

شريط بثلاثة ألوان يقيس وضوح الوجه مباشرة أثناء تسجيل بصمة الوجه.

- المستهلك يوفّر: `data-level` من 1 إلى 3 يتحدّث مع كل إطار من الكاميرا (حجم الوجه، موقعه، استقامته، الإضاءة، الحدّة)، والجملة فوقه.
- عند المستوى 3 لمدة ثانية تُلتقط الصورة تلقائياً. الكلمات تحت الشريط دائماً ظاهرة.
