# StatusPill

شارة الحالة: كلمة واحدة أو اثنتان، ولونها له معنى ثابت.

- `present` حاضر/متصل، `absent` غائب/منقطع، `late` متأخر، `excused` غائب بعذر، `left` انصرف، `quiet` لم يصل بعد أو معلومة محايدة.
- المستهلك يوفّر: `<span class="hd-pill hd-pill-…">` والكلمة. الكلمة إلزامية، فاللون وحده لا يكفي.
- لا تستخدمها للزينة ولا للأقسام.
