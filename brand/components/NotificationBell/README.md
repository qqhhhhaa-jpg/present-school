# NotificationBell

جرس الإشعارات بعدد غير المقروء، والضغط عليه يفتح قائمة الإشعارات.

- المستهلك يوفّر: `hd-bell` وأيقونة الجرس، و`hd-count` بالعدد (أكثر من 99 يكتب 99+، وصفر يخفي الدائرة). `hd-bell-on` أثناء فتح القائمة.
- مكانه أعلى الصفحة بجانب البحث على الكمبيوتر، وأعلى الشاشة الرئيسية في التطبيق.
