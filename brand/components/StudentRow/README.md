# StudentRow

بطاقة طالب: الحرف الأول، الاسم، الصف والمعلومة الأهم اليوم، وشارة الحالة.

- المستهلك يوفّر: الاسم والصف وسطر المعلومة والحالة. البطاقة تأخذ أرضية الحالة (`hd-state-present` / `late` / `absent`) فقط حين تكون الحالة هي الخبر، مثل لحظة الوصول.
- تُستخدم في تطبيق ولي الأمر (أولادي اليوم)، نتائج البحث، وقوائم الحضور.
