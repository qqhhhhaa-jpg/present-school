# حاضر على السيرفر (Supabase) · الأمان والحجم الكبير

`schema.sql` يبني قاعدة البيانات كاملة. جرّبته على PostgreSQL وطلع بدون أخطاء، وفحصت الصلاحيات:

| الفحص | النتيجة |
|---|---|
| ولي أمر يشوف طلاب غير أولاده | ممنوع |
| مدرسة تشوف بيانات مدرسة ثانية | ممنوع |
| مدرس يشوف شعب برا صلاحيته | ممنوع (والشعب الجديدة بنفس الصف تنضاف إله وحدها) |
| مدرس مطفية عنده صلاحية النشر ينشر | ممنوع |
| ولي أمر ينشر أو يغيّر درجة | ممنوع |
| تعديل درجة بدون سبب | ممنوع، وكل تعديل ينسجل بسجل دائم |
| مسح أو تزوير سجل العمليات أو سجل الدرجات | ممنوع حتى على الإدارة |
| ملف بدون صلاحية على المنشور | ممنوع (Storage خاص وروابط مؤقتة) |

## ليش يتحمّل حجم كبير
- كل جدول بيه `school_id` وفهارس، فالمنصة تخدم مدارس كثيرة بنفس القاعدة.
- البصمات بجدول مقسّم شهرياً: ملايين السجلات وتبقى سريعة. `add_attendance_month('2028-09-01')` يضيف أشهر جديدة.
- الملفات (PDF وصور وفيديو لحد 300MB) بـ Supabase Storage، مو داخل قاعدة البيانات.
- الإشعارات والمنشورات والدرجات مفهرسة للقراءة الأحدث أولاً، والواجهة تقرأها صفحة صفحة.

## الحماية
- Row Level Security مفعّل ومفروض على كل جدول، ومحد يوصل لشي بدون تسجيل دخول.
- الدخول عن طريق Supabase Auth: رمز SMS لأولياء الأمور والطلاب، ويوزر ورمز (مشفّر bcrypt) للإدارة والمدرسين.
- أجهزة البصمة ترسل لـ Edge Function بالرقم التسلسلي وسر مشفّر، ومنع تكرار نفس البصمة.
- `vercel.json` يضيف حماية المتصفح: HTTPS إلزامي، منع تضمين المنصة بمواقع ثانية، وسياسة محتوى (CSP) تمنع تشغيل أي كود غريب.

## المشروع على Supabase
- اسم المشروع: **hader** (فرانكفورت، الأقرب للعراق) · الرابط: `https://gdszxtzprkxydujbhcun.supabase.co`
- القاعدة منزّلة وجاهزة: 24 جدول، كلها مقفولة بالصلاحيات، ومخزنين ملفات خاصين (school-files و faces).
- انفحصت على السيرفر نفسه: ولي أمر يشوف ابنه بس، مدرسة ما تشوف مدرسة ثانية، المدرس يشوف شعبه بس، والمدرس اللي مطفية عنده صلاحية النشر ما ينشر، وتعديل درجة بدون سبب مرفوض، وولي الأمر ما يكدر يغيّر درجة، وسجل العمليات ما ينزوّر ولا ينمسح حتى من الإدارة.
- فحص الأمان مال Supabase: ماكو تحذير مفتوح غير `log_action` (مقصود: كل مستخدم يكتب بسجل مدرسته باسمه بس) وأقسام البصمات الشهرية (مقفولة ومحد يوصلها إلا من الجدول الرئيسي).

## التشغيل
1. (صار) القاعدة منزّلة على مشروع hader. لمشروع جديد: SQL Editor → الصق `schema.sql` → Run.
2. Authentication → فعّل Phone (SMS) وربطه بمزوّد رسائل (مثلاً Twilio).
3. انشر المنصة على Vercel، واربطها بمفاتيح المشروع (URL و anon key).
